# Scribble Lists ✿

A tiny, doodly list app for groceries, wishlists, to-dos and anything else.

**Live:** https://scribble-lists.vercel.app

- Lists sorted by type (Groceries, Wishlist, To-do, Anything), with your own groups inside each list
- Hand-drawn doodles, a little mochi mascot, crayon scribble tick-offs and small celebrations
- Plain HTML/CSS/JS, no build step; lists are saved in the browser (localStorage)

## Run locally

Open `index.html` in a browser, or serve the folder with any static server.

## Deploy

```
npx vercel deploy --prod
```
